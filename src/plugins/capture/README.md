# capture

> Standard plugin (agent core) — Adds editor commands to the registry so the tools page (and later MCP) can take pictures of the running game: `editor.capture` (one screenshot), `editor.series` (a timed series of screenshots, best effort, one call — never split into chunks, R1) and `editor.seriesStop` (ends a running series early, R2).
